# 10. 时间转换

go-pbmo 自动处理 `time.Time` ↔ `*timestamppb.Timestamp` 之间的转换，无需手动编写转换代码

## 自动时间转换

默认启用，在创建转换器时自动开启：

```go
converter := pbmo.NewBidiConverter(EventPB{}, EventModel{})
// AutoTimeConversion 默认为 true
```

### PB → Model

```go
type EventPB struct {
    Id        uint64
    Name      string
    CreatedAt *timestamppb.Timestamp
    UpdatedAt *timestamppb.Timestamp
}

type EventModel struct {
    ID        uint64 `pbmo:"Id"`
    Name      string
    CreatedAt time.Time
    UpdatedAt time.Time
}

converter := pbmo.NewBidiConverter(EventPB{}, EventModel{})

var model EventModel
converter.ConvertPBToModel(pb, &model)
// CreatedAt 和 UpdatedAt 自动从 *timestamppb.Timestamp 转为 time.Time
```

### Model → PB

```go
var pb EventPB
converter.ConvertModelToPB(model, &pb)
// CreatedAt 和 UpdatedAt 自动从 time.Time 转为 *timestamppb.Timestamp
```

## 禁用自动时间转换

```go
converter := pbmo.NewBidiConverter(EventPB{}, EventModel{},
    pbmo.WithAutoTimeConversion(false),
)
```

## 手动时间转换

go-pbmo 提供独立的时间转换函数：

```go
// time.Time -> *timestamppb.Timestamp
timestamp := pbmo.TimeToProtoTimestamp(time.Now())

// *timestamppb.Timestamp -> time.Time
t := pbmo.ProtoTimestampToTime(timestamp)

// 指针形态（PB 的可选时间字段常用）
timestamp = pbmo.TimePointerToProtoTimestamp(&someTime)
tp := pbmo.ProtoTimestampToTimePointer(timestamp)
```

四个函数都自带 nil 与零值处理，不需要额外的「安全」变体：

```go
pbmo.ProtoTimestampToTime(nil)        // time.Time 零值（IsZero() 为 true）
pbmo.ProtoTimestampToTimePointer(nil) // nil
pbmo.TimeToProtoTimestamp(time.Time{}) // nil，零时间不会被写成 1970
pbmo.TimePointerToProtoTimestamp(nil) // nil
```

零时间转成 `nil` 而不是 Unix 纪元这一点值得留意：PB 里 `nil` 表示
「没有这个时间」，而 1970-01-01 是一个真实时刻，两者不该混同

## 时间转换函数一览

| 函数 | 说明 |
|------|------|
| `TimeToProtoTimestamp(t time.Time) *timestamppb.Timestamp` | Time → Timestamp，零时间返回 nil |
| `ProtoTimestampToTime(ts *timestamppb.Timestamp) time.Time` | Timestamp → Time，nil 返回零值 |
| `TimePointerToProtoTimestamp(t *time.Time) *timestamppb.Timestamp` | *Time → Timestamp，nil 返回 nil |
| `ProtoTimestampToTimePointer(ts *timestamppb.Timestamp) *time.Time` | Timestamp → *Time，nil 返回 nil |
| `IsTimeType(t reflect.Type) bool` | 判定是否为 `time.Time` |
| `IsTimestampPtrType(t reflect.Type) bool` | 判定是否为 `*timestamppb.Timestamp` |

## 注意事项

- 自动时间转换仅处理 `time.Time` ↔ `*timestamppb.Timestamp` 的配对
- 如果 PB 使用 `string` 存储时间，需要通过字段转换器处理
- `nil` 的 `*timestamppb.Timestamp` 会转为 `time.Time` 零值
- `time.Time` 零值会转为 `nil` 的 `*timestamppb.Timestamp`
