# 12. 错误处理

本库**不是**一套错误类型层级，而是**一个值类型加一个分类枚举**

```go
type Error struct {
    Msg  string
    Type ErrorType
}
```

`Error` 是值类型而非指针，这样预定义错误可以直接用 `errors.Is` 比较，
分类也能在被 `%w` 包装之后由 `errors.As` 取回来

## 分类枚举

```go
const ErrTypeUnknown ErrorType = 0 // ClassifyError 对非本库错误的返回值

const (
    ErrTypeConversion   ErrorType = iota + 20000 // 20000 转换错误
    ErrTypeValidation                            // 20001 校验错误
    ErrTypeNilValue                              // 20002 空值错误
    ErrTypeTypeMismatch                          // 20003 类型不匹配
    ErrTypeFieldMapping                          // 20004 字段映射错误
    ErrTypeBatch                                 // 20005 批量操作错误
    ErrTypeDesensitize                           // 20006 脱敏错误
    ErrTypeRegistry                              // 20007 注册中心错误
)
```

## 构造

每个分类有一个构造函数，消息会被加上分类前缀：

```go
err := pbmo.NewConversionError("字段 %s 转换失败", "Email")
err.Error() // "转换错误: 字段 Email 转换失败"
```

| 构造函数 | 分类 |
|---|---|
| `NewConversionError` | `ErrTypeConversion` |
| `NewValidationError` | `ErrTypeValidation` |
| `NewNilValueError` | `ErrTypeNilValue` |
| `NewTypeMismatchError` | `ErrTypeTypeMismatch` |
| `NewFieldMappingError` | `ErrTypeFieldMapping` |
| `NewBatchError` | `ErrTypeBatch` |
| `NewDesensitizeError` | `ErrTypeDesensitize` |

本库自身不做参数校验，`NewValidationError` 是给调用方在自己校验之后
统一错误分类用的

## 判定分类

```go
if pbmo.ClassifyError(err) == pbmo.ErrTypeNilValue {
    // 传进来的是 nil
}
```

也有几个常用分类的快捷判定：

```go
pbmo.IsConversionError(err)
pbmo.IsValidationError(err)
pbmo.IsNilValueError(err)
pbmo.IsTypeMismatchError(err)
```

两者都穿透 `%w` 包装：

```go
err := pbmo.NewConversionError("字段 %s 转换失败", "Email")
wrapped := fmt.Errorf("处理用户请求: %w", err)

pbmo.ClassifyError(wrapped)     // ErrTypeConversion
pbmo.IsConversionError(wrapped) // true

var e pbmo.Error
errors.As(wrapped, &e)          // true，e.Type == ErrTypeConversion
```

非本库的错误返回 `ErrTypeUnknown`（取值 0），而不是被误判成某一类：

```go
pbmo.ClassifyError(errors.New("来自别处")) // ErrTypeUnknown
```

## 预定义错误

固定场景的错误是预先分配的变量，用 `errors.Is` 比较：

```go
var (
    ErrPBMessageNil      = Error{Msg: "PB消息不能为空", Type: ErrTypeNilValue}
    ErrModelNil          = Error{Msg: "Model不能为空", Type: ErrTypeNilValue}
    ErrMustBePointer     = Error{Msg: "目标必须是指针类型", Type: ErrTypeTypeMismatch}
    ErrMustBeSlice       = Error{Msg: "源必须是切片类型", Type: ErrTypeTypeMismatch}
    ErrMustBeStruct      = Error{Msg: "目标必须是结构体类型", Type: ErrTypeTypeMismatch}
    ErrConverterExists   = Error{Msg: "转换器已存在", Type: ErrTypeRegistry}
    ErrConverterNotFound = Error{Msg: "转换器未找到", Type: ErrTypeRegistry}
)
```

```go
if errors.Is(err, pbmo.ErrMustBePointer) {
    // 目标忘了传指针
}
```

## 批量转换的错误

安全批量转换不因单个元素失败而中断，错误逐元素收集在 `BatchResult` 里：

```go
models, result := pbmo.SafeFromPBs[UserPB, UserModel](pbs)

fmt.Printf("成功 %d，失败 %d\n", result.SuccessCount, result.FailureCount)
for _, item := range result.Results {
    if !item.Success {
        fmt.Printf("第 %d 个失败: %v\n", item.Index, item.Error)
    }
}
```

结果切片与输入保持下标对齐，失败处留 `nil`，这样失败项能对回原始输入

普通批量转换（`FromPBs` / `ToPBs`）遇到第一个错误即返回：

```go
models, err := pbmo.FromPBs[UserPB, UserModel](pbs)
if err != nil {
    if pbmo.ClassifyError(err) == pbmo.ErrTypeBatch {
        // 批量转换环节出错
    }
}
```
