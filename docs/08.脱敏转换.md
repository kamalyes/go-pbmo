# 08. 脱敏转换

脱敏在**主模块**里，由 `WithDesensitize` 开关控制，**默认关闭**

它不是转换之后再跑一遍反射遍历，而是编织进既有的 unsafe 偏移拷贝计划：
带 `desensitize` tag 的字段在计划构建期就解析好脱敏器，转换时顺着同一次拷贝
把值写成脱敏后的结果

```go
import (
    "github.com/kamalyes/go-pbmo"
)

bc := pbmo.NewBidiConverter(UserPB{}, UserModel{}, pbmo.WithDesensitize(true))
```

## 两条关键保证

**只写目标端，绝不回写源对象**

```go
model := &UserModel{Phone: "13800138000"}

var pb UserPB
_ = bc.ConvertModelToPB(model, &pb)

// pb.Phone    == "138****8000"
// model.Phone == "13800138000"   ← 调用方的数据没有被改坏
```

这是「转换中途脱敏」能否成立的前提若源被就地改写，调用方手里的 Model 在管道
中途就失真了，后续落库、重试、比对全部跟着错

**无 tag 的类型零代价**

没有任何字段带 tag 时，不会装上包装闭包，拷贝计划与关闭脱敏时逐字节相同
开关开着也不收费：

| 基准（Apple M4, -count=3 -cpu=10） | ns/op | allocs |
|---|---|---|
| 无 tag + 开关关闭 | 12.6–13.5 | 0 |
| 无 tag + 开关开启 | 12.8–12.9 | 0 |
| 带 tag + 开关关闭 | 12.8–13.0 | 0 |
| 带 tag + 开关开启 | 103.8–104.6 | 1 |
| 带 tag + 开关开启（并发 10） | 25.2–25.8 | 1 |

## 脱敏 Tag

tag 写在 **Model** 一侧，两个方向都由它说话

protoc 生成的结构体不带 `desensitize` tag，所以 Model→PB 时 tag 在源、
PB→Model 时 tag 在目标解析按「源字段优先、否则目标字段」取值，
因此不必按方向分叉：

```go
type UserModel struct {
    ID       uint64 `pbmo:"Id"`
    Name     string `desensitize:"name"`
    Phone    string `desensitize:"mobilePhone"`
    Email    string `desensitize:"email"`
    IDNo     string `desensitize:"identityCard"`
    Card     string `desensitize:"bankCard"`
    Addr     string `desensitize:"address"`
    Token    string `desensitize:"secret"`
    Serial   string `desensitize:"jump(3,-4,1)"`
    Memo     string // 无 tag，不动
}
```

实测输出：

| tag | 输入 | 输出 |
|---|---|---|
| `name` | 张三丰 | `张**` |
| `mobilePhone` | 13800138000 | `138****8000` |
| `email` | zhangsan@example.com | `z*****an@example.com` |
| `identityCard` | 11010119900307123X | `110101********123X` |
| `bankCard` | 6222021234567890123 | `6222 **** **** **** 0123` |
| `address` | 北京市海淀区中关村大街1号院 | `北京市海*******1号院` |
| `secret` | sk-live-abcdefghijklmnop | `sk-l****************mnop` |
| `jump(3,-4,1)` | ABCDEFGHIJKLMNOP | `ABC*********MNOP` |

完整的 tag 名清单（含别名与参数化写法）见 `go-toolbox/pkg/desensitize` 的内置类型表

## 作用范围

只处理**目标字段是字符串形态**（`reflect.String`，含 `type Name string`
这类命名类型）的顶层字段其余形态返回原值：

- `*string`：在 `fieldSameType` 下是指针直拷，就地改写会污染源对象共享的那块内存
- 切片、映射、嵌套结构体：由各自的嵌套拷贝计划搬运，而嵌套计划按
  「源类型+目标类型」全进程共享，承载不了 per-converter 的开关——
  这与 `AutoTimeConversion` 对嵌套同样不生效是一致的

```go
type Outer struct {
    Phone string `desensitize:"mobilePhone"` // 生效
    Inner Inner                              // Inner 里的 tag 不生效
}
```

这些形态需要脱敏时，在输出层调 `desensitize.Desensitization`：

```go
m, err := pbmo.FromPB[UserPB, UserModel](pb)
err = desensitize.Desensitization(m)
```

## 开关控制

```go
// 构造时
bc := pbmo.NewBidiConverter(UserPB{}, UserModel{}, pbmo.WithDesensitize(true))

// 构造后切换：开关影响拷贝计划的构建结果，会自动让已建好的计划失效后重建
bc.WithDesensitize(false)
```

开启不等于一定会脱敏：只有带 tag 的字符串字段才会被处理

## tag 名拼错会怎样

规则名未注册时**保持原值**，不会写空字符串：

```go
type M struct {
    Phone string `desensitize:"moblePhone"` // 拼错了
}
// Phone 原样输出
```

这是刻意的取舍——一次拼错不该静默清空生产数据
但它也意味着拼错不会报错，所以 tag 名建议对照上游清单核对

`desensitize:"-"` 与空 tag 都表示显式跳过

## 与转换器叠加

字段同时注册了 Transformer 时，**先转换再脱敏**，脱敏是写入目标前的最后一道：

```go
bc.RegisterTransformer("Phone", func(v interface{}) interface{} {
    return normalize(v.(string))
})
// 结果是 normalize 之后再脱敏
```
