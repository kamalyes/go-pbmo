# 09. 安全转换

`SafeConverter` 在转换前拦截 nil 与 typed-nil 指针，避免转换引擎 panic
它位于主模块，没有任何第三方依赖

## SafeConverter

```go
converter := pbmo.NewSafeConverter(UserPB{}, UserModel{})
```

### 安全 PB → Model

```go
var model UserModel
err := converter.SafeConvertPBToModel(pb, &model)
// 自动处理 nil 值，不会 panic
```

如果 `pb` 为 nil 或无效，返回分类为 `ErrTypeNilValue` 的错误而非 panic

### 安全 Model → PB

```go
var pb UserPB
err := converter.SafeConvertModelToPB(model, &pb)
```

## 安全字段访问

v0.3.0 起本库不再转出字段访问函数

原先的 `SafeFieldAccess` / `SafeGetField` / `SafeGetNestedField` 都只是
`safe.New(obj).Field(name)` 的一行转发，本库没有增加任何语义，
却让整个 `go-toolbox/pkg/safe` 及其依赖进入每个使用者的构建图，因此移除

需要链式安全访问时直接用上游：

```go
import "github.com/kamalyes/go-toolbox/pkg/safe"

safe.New(user).Field("Name")                  // 原 pbmo.SafeGetField
safe.New(user).At("Profile.Avatar.URL")       // 原 pbmo.SafeGetNestedField
safe.New(user).Field("Profile").Field("Avatar") // 原 converter.SafeFieldAccess
```

## 安全批量转换

```go
models, result := pbmo.SafeFromPBs[UserPB, UserModel](pbs)

// 自动跳过 nil/零值元素
for _, item := range result.Results {
    if !item.Success {
        log.Printf("元素 %d 转换失败: %v", item.Index, item.Error)
    }
}
```

安全批量转换对每个元素做 nil 与零值检查，在转换前就跳过无效元素，
单个元素失败不会中断整批

> 💡 更推荐泛型版本 `SafeFromPBs[P, M](pbs)`，类型更安全、调用更简洁

## safe 的 Access 链式调用

如需链式安全访问，引入上游包即可，它与本库互不影响：

```go
import "github.com/kamalyes/go-toolbox/pkg/safe"

// 终点取值方法自带默认值，路径取不到时不必自己写 if/else
theme := safe.New(user).
    Field("Profile").
    Field("Settings").
    Field("Theme").
    String("default")

// 点分路径一次到位，语义与逐级 Field 相同
avatar := safe.New(user).At("Profile.Avatar.URL").StringOr("none.png")

// 需要显式判断存在性时才用 IsValid
if safe.New(user).Field("Profile").IsValid() {
    // Profile 存在
}
```

## 错误类型

本库只有一个 `Error` 值类型，nil 值错误由分类 `ErrTypeNilValue` 标识，
没有单独的 `NilValueError` 类型：

```go
err := converter.SafeConvertPBToModel(nil, &model)
if pbmo.IsNilValueError(err) {
    fmt.Println("nil 值错误:", err)
}
```

固定场景用预定义错误比较更直接：

```go
if errors.Is(err, pbmo.ErrPBMessageNil) {
    // 传进来的 PB 是 nil
}
```

两者都穿透 `%w` 包装，详见 [12.错误处理](12.错误处理.md)
